# Prostate cancer spatial proteomic atlas

Web-only reviewer mirror of the Myriad reference-cohort atlas.

The interactive 3D tumor map includes 403 reference tumors and links to the corresponding spatial cell-state maps and cell-fraction plots. Coordinates, archetype assignments, and image assets are preserved from the local atlas export.

Open https://wchenlab.github.io/prostate-atlas-review/ without an institutional account.

Search indexing is discouraged using robots metadata; this repository and its website are publicly accessible.
